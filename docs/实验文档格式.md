# 实验文档格式：版本 1

实现：[schema.ts](../experiments/schema.ts) · [storage.ts](../experiments/storage.ts)。

文件用于复现实验参数。恢复时重新计算结果；API Key、激活信息、AI 回复、选中对象、缩放、临时输入和求解结果均不属于实验文件。

## 文档字段

| 字段 | 约定 |
| --- | --- |
| `format` | 固定为 `mechmat-experiment` |
| `schemaVersion` | 文件结构版本，当前为 1 |
| `calculationVersion` | 计算模型版本，当前为 1；对比要求一致 |
| `id`、`name` | 非空标识与名称，最多 120 个字符 |
| `module` | `fundamentals`、`axial`、`bending`、`torsion`、`buckling`、`stress`、`combined`、`solver`、`section` |
| `createdAt`、`updatedAt` | 可解析的日期字符串；应用生成 ISO 时间 |
| `model` | 以下三种模型之一，必须与模块匹配 |

导入文件最大 2 MB。校验成功后一次替换对应模块，可撤销；任何版本、数值、几何或引用错误都保留当前实验。

## 基础模块模型

`model.kind` 为 `simulation`，`parameters` 使用该模块的字段白名单。每个模块保存独立材料和参数：拉伸的 `bendModulus` 与弯曲的同名字段属于不同文档，互不覆盖。完整字段表以 `MODULE_FIELDS` 为准。

| 参数类型 | 文件单位 |
| --- | --- |
| 基础力和压力 | N |
| 杆长、梁跨度、轴长、载荷位置 | m |
| 截面尺寸、偏心距 | mm |
| 面积、惯性矩 | mm²、mm⁴ |
| 基础模块弹性/剪切模量 | GPa |
| 应力、屈服强度 | MPa |
| 输入扭矩 | N·m |
| 角度 | ° |
| 泊松比、扭矩分流比例 | 无量纲 |

尺寸和模量为有限正数；基本载荷大小允许 0；应力、偏心距可以带符号。泊松比为 `[0, 0.5)`，分流比例为 `[0, 1]`，斜截面角为 `[0, 90]`。梁上载荷必须位于梁内。输入导致计算溢出时拒绝导入。

`bendSection` 等截面对象使用基础 `SectionType`，例如 `rectangle`、`hollow_circle`。矩形宽高在截面对象中保存。旧参考宽高字段仅兼容保留；报告按实际参与计算的截面尺寸列出参数，弯曲图示厚度也由该截面决定。

## 求解器模型

`model.kind` 为 `solver`，`coordinateUnit` 固定为 `mm`。保存 `nodes`、`elements`、`loads`：

- 节点：唯一 ID、x/y 坐标、支座类型、水平/竖直/转角约束。
- 单元：唯一 ID、梁/桁架类型、起止节点、截面和材料。截面 A/I 为 mm²/mm⁴，宽高为 mm；E/G/屈服强度为 MPa。
- 荷载：唯一 ID、集中力/分布荷载/力矩类型、作用对象、数值、方向角及相对位置。集中力用 N，分布荷载用 N/m，力矩用 N·m，相对位置为 0 至 1。

引用须存在；数值须有限；同一单元不能引用同一个起止节点。允许保存尚未完成的建模草稿；文档校验通过不代表结构一定可求解。求解时仍检查零长度单元、支承和矩阵等条件。

求解结果不随文件保存。修改模型后旧结果失效，恢复模型后重新求解。

## 截面工具模型

`model.kind` 为 `section`，`coordinateUnit` 固定为 `mm`：

- `sectionType` 使用独立的 `SectionToolType`，如 `hollow-circle`、`i-beam`、`draw`，与基础截面类型分开。
- `parameters` 保存对应预设的几何输入；校验有限数值、最小尺寸、内外径及壁厚/翼缘关系。
- `paths` 保存轮廓 ID、顶点 x/y、内孔标记及闭合状态。闭合轮廓至少有三个顶点；允许保存未完成的绘图草稿。
- `displayUnit` 可为 `mm`、`cm` 或 `m`，只改变显示换算；顶点与几何参数始终为 mm。

恢复时重新计算多边形属性。报告统一列出 mm 系列单位，并保留显示单位记录。

## 版本与存储

唯一支持的旧文件是显式版本 0：`{format, schemaVersion: 0, module, name, state}`。其中 `state` 为基础模块参数集合；迁移仅保留指定模块白名单字段，丢弃附带凭据和其他模块参数。未知版本及未定义的旧格式拒绝导入。

工作区以 `mechmat_workspace_v1` 保存在浏览器本地，包含九个模块的最近文档、当前模块和最多 50 个命名存档。字段经过校验再写入；存储失败保留页面编辑和原存档。损坏数据会暂停自动写入，用户显式重新启用时才用当前工作区替换原恢复数据。

撤销/重做历史每模块最多 50 步，只在当前页面会话保留。工况对比最多四个同模块、同计算版本的有效快照；切换模块或刷新会清空当前对比组，可重新从命名存档加入。对比组可随 CSV/PDF 导出。

可导入的四个例题：[拉伸](./examples/axial.json) · [弯曲](./examples/bending.json) · [扭转](./examples/torsion.json) · [压杆](./examples/buckling.json)。
