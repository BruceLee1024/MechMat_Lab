## 2. 任务详情

### T01：建立基线并修复类型契约

- 范围：`package.json`、`solver/SolverTypes.ts`、报错的旧求解器、`solver/components/DiagramPanel.tsx`、`utils/exportPdf.ts`。
- 工作：记录构建、类型和实际调用基线；增加类型检查命令；修复 8 处现有报错；确认旧求解器是使用、兼容还是待退出状态。
- 对未接入的 PDF 工具明确保留并补依赖或暂时移除的处理方式；不得仅为消除错误把文件排除在类型检查外。
- 验收：干净安装后类型检查、构建均通过；结果字段有明确单位和语义；不得使用 `any`、假数据或无依据的可选字段掩盖缺失结果。
- 交付：基线记录、契约修复、可重复运行的检查命令。

### T02：统一单位和结果数据定义

- 范围：`types.ts`、`solver/SolverTypes.ts`、计算边界；建议新增 `mechanics/units.ts`。
- 工作：定义内部 N、mm、MPa、N·mm 单位；区分输入、内部和显示单位；定义计算状态、假设和诊断结构。
- 验收：1 kN＝1000 N、1 m＝1000 mm、1 GPa＝1000 MPa、1 N·m＝1000 N·mm；同一工况换单位后物理结果一致；旧实验值不被隐式重解释。
- 交付：单位工具、单位对照说明及转换验证。

### T03：重做数值输入校验

- 范围：`components.tsx` 的滑块/输入控件及使用处、求解器精确输入。
- 工作：参数级正值、非负、带符号和区间约束；编辑状态与已提交值分离；关联参数联动验证；输入错误提示和标签关联。
- 验收：零载荷和端点位置可输入；允许带符号的参数可输入负值；尺寸不接受零或负值；清空、负号、小数点和科学计数法不会产生 NaN；缩短梁长后处理越界载荷位置。
- 交付：统一输入组件及各参数约束表。

### T04：提取核心公式计算层

- 范围：拉伸、弯曲、扭转、压杆、应力模块与共享截面属性；建议新增 `mechanics/`。
- 工作：先迁移现有有效计算，保持 UI 可用；视图消费结构化结果；让推导、摘要、图表和 AI 使用同一计算值。
- 验收：默认与代表工况迁移前后结果一致；所有计算可脱离 React 调用；非法参数返回诊断；示意塑性/超临界模型有明确假设，弹性公式不用于解释塑性变形结果。
- 交付：纯计算函数及逐模块迁移记录。

### T05：建立独立计算回归案例

- 范围：计算层、统一求解入口；新增最小必要测试工具和参考案例。
- 工作：覆盖拉伸、扭转、跨中简支梁、偏置载荷简支梁、悬臂梁、欧拉压杆、纯剪切和三种基础截面；覆盖无效及奇异输入。
- 验收：参考值由独立解析公式或可追溯参考推得；非零解析结果相对误差 ≤ 10⁻⁶，零值设有对应单位的绝对容差；离散案例另定阈值；故意引入单位转换错误会使验证失败。
- 交付：参考参数、预期值、来源/推导与回归命令。

### T06：修复 AI 流式与请求生命周期

- 范围：`ai.tsx`，必要时提取 SSE 解析和请求服务；核对现有代理的实际使用情况。
- 工作：保留跨块数据，按完整 SSE 事件解析；正确结束和释放 reader；加入 AbortController、超时、停止和失败重试；组件卸载与模块切换时取消请求。
- 验收：中文字符及 JSON 在任意边界拆块仍能还原；处理 CRLF、结束标记、空响应和 HTTP 错误；取消后不追加旧回复；重复发送受控；未配置 Key 时保留设置入口。
- 交付：传输修复、可控流响应验证；实测未提供 Key 的模型不标记为验证通过。

### T07：桌面工作台和手机布局

- 范围：`index.tsx`、`Sidebar`、实验工具栏及模块容器。
- 工作：桌面分栏和专注模式；手机实验/理论/AI 面板切换；触控及键盘分隔器；清理模块切换计时器，避免快速切换导致旧页面回跳。
- 验收：1440×900、1024×768、390×844 无主布局横向溢出；实验图与输入可读；面板切换不丢参数；菜单可关闭；快速连续导航落在最后一次选择的模块。
- 交付：布局改动、桌面和手机截图、主导航交互验证。

### T08：实验文档及模块状态分离

- 范围：`types.ts`、`index.tsx`、求解器和截面模块；建议新增 `experiments/`。
- 工作：建立带版本的实验 schema；材料、截面和各模块参数独立表达；处理同名重复类型；模型和界面状态分离；定义旧数据迁移及未知版本处理。
- 验收：拉伸修改不会意外改变已有弯曲存档；实验可完整序列化与恢复；求解器保留节点/单元/载荷；截面绘图保留路径与单位；不含 API Key、激活信息或临时请求状态。
- 交付：实验数据契约、校验/迁移函数、示例文件。

### T09：自动恢复、存档和撤销重做

- 范围：实验状态层、工具栏、存档列表。
- 工作：自动保存最近实验；命名、另存为、删除、模块重置；有限长度历史；一次滑块拖动合并为一次历史操作；捕获存储不可用或配额不足。
- 验收：修改后刷新恢复；切换模块再返回保留数据；重置可撤销；撤销后新编辑清空重做分支；损坏文件和保存失败不会覆盖当前有效实验；状态明确显示已保存或保存失败。
- 交付：存档与历史功能及恢复验证。

### T10：例题库与工况对比

- 范围：实验预设、对比视图、结果指标组件。
- 工作：首批拉伸、弯曲、扭转、压杆各至少一个可复现例题；保存参考工况；最多 4 个同模块工况比较，显示关键输入、绝对变化和相对变化。
- 验收：加载例题得到参考结果；修改材料或截面时结果实时变化；基准为零时相对变化显示“不适用”；不同模块、不同模型版本不可直接混比；对比不修改原存档。
- 交付：例题数据、对比视图、真实结果验证。

### T11：实验 JSON、CSV、PDF 导出

- 范围：`utils/exportPdf.ts`、实验序列化、报告入口。
- 工作：JSON 导入导出；CSV 工况数据；按需加载 PDF 依赖；报告包含参数、单位、公式、图表、结果和计算版本；导出时使用稳定快照。
- 验收：JSON 重新导入得到相同参数和结果；CSV 列名与单位完整；中文 PDF 多页可读、不截断关键表格；文件名称有效；成功或失败后界面样式均恢复；所有导出不含凭据。
- 交付：三个导出入口、导入校验、样例报告。

### T12：弯曲曲线、精确极值和参数扫描

- 范围：`modules/BendingModule.tsx`、弯曲计算函数与曲线组件。
- 工作：计算沿梁挠度、剪力和弯矩；点击/触摸查看坐标值；计算真实最大挠度位置；区分载荷点与极值点；单变量扫描长度、载荷或截面高度。
- 验收：跨中载荷与偏置载荷都满足支座位移为零；反力平衡；偏置工况最大挠度不被强制标在载荷点；高度翻倍时矩形截面惯性矩变为 8 倍；载荷点的剪力跳变不被平滑抹掉。
- 交付：曲线、探针、极值与扫描结果，以及独立解析验证。

### T13：压杆边界条件与适用范围

- 范围：`modules/BucklingModule.tsx`、实验 schema 和压杆计算。
- 工作：加入铰铰 μ=1、固固 μ=0.5、固自由 μ=2、固铰 μ≈0.699；更新支座示意、计算长度、长细比和临界载荷；提示欧拉弹性公式适用条件。
- 验收：其他参数相同时，固固与固自由临界载荷分别为铰铰的 4 倍和 1/4；使用弱轴惯性矩；临界应力超过适用弹性范围时结果带模型限制说明，不标成精确承载力。
- 交付：四种边界、相关存档迁移和计算验证。

### T14：三维应力与强度判据

- 范围：`modules/StressModule.tsx`、应力计算和结果组件。
- 工作：保留平面模式；三维模式启用 σx、σy、σz、τxy、τyz、τzx；对称矩阵特征分解；展示主应力、主方向、von Mises 和 Tresca。
- 验收：纯拉伸、纯剪切、静水压力和一般三维案例正确；纯剪切主应力为 τ、0、−τ；静水压力的 von Mises 为零；平面模式与现有变换一致；重复特征值不产生虚假唯一主方向。
- 交付：三维分析、能力说明和张量不变量验证。

### T15：材料与自定义截面跨模块复用

- 范围：`MaterialSelector`、`calculateSectionProperties`、`SectionModule.tsx`、实验资源层。
- 工作：扩展已有材料库与绘图能力；保存自定义资源；统一 A、Iy、Iz、形心和抗弯模量；定义材料适用模型与截面计算能力；建立到学习模块和求解器的映射。
- 验收：同一截面各模块几何属性一致；空心圆校验 R>r；对各向同性材料满足 G=E/[2(1+ν)] 或明确自定义覆盖；未支持的非圆截面扭转不套用圆轴极惯性矩公式；混凝土等材料不默认按钢材屈服模型解释。
- 交付：资源保存复用、适用能力标识和映射验证。

### T16：求解器建模、历史和模板

- 范围：`solver/SolverModule.tsx`、`ModelingPanel.tsx`、实验历史层。
- 工作：网格吸附、坐标输入、节点/单元/荷载编辑、模型另存为；模板分类；建模撤销重做；绘图区触控与键盘操作。
- 验收：节点删除不留下悬空引用；修改模型后旧结果失效；撤销恢复完整模型；模板加载有明确结果；导入模型再求解可复现；零长度单元不能提交。
- 交付：建模流程、模型存档和交互验证。

### T17：求解诊断、残差及耗时求解处理

- 范围：`UnifiedSolver.ts`、矩阵工具、模型诊断和结果区；必要时新增 Worker。
- 工作：检查无约束、断开、重复/零长度单元、无效引用和材料；奇异矩阵给出可理解的诊断；计算力与力矩平衡残差；测量模型规模及主线程阻塞后决定 Worker 边界。
- 验收：已知无效结构能指向具体对象或原因；有效结构平衡残差达案例容差；模型更新后旧任务结果被丢弃；耗时任务可取消；Worker 和同步路径数值一致；不把所有矩阵错误都解释成支座不足。
- 交付：诊断、残差、性能基线和必要的异步求解。

### T18：AI 基于实验结果解释与对比

- 范围：AI 上下文、对话保存、结果/对比入口。
- 工作：加入解释结果、比较工况、实验建议；输入包含本地计算结果、单位、工况 ID 和假设；按模块保存对话；失效或越界结果明确标注。
- 验收：能识别当前工况与对比差异；切换模块不串用旧结果；AI 建议可由用户显式应用，不自动覆写模型；无 Key 时基础计算和例题仍可用；凭据不写入文档或日志。
- 交付：三个快捷入口、结构化上下文与模拟服务验证；真实模型另列实测范围。

### T19：首页继续实验与模块搜索

## 3. 首批开发包

首批限定为可靠性改进，避免同时改动所有界面和力学模型：

1. T01：让类型检查通过，冻结有效计算基线。
2. T02：先统一单位和结果定义。
3. T03：修复输入规则和边界，复现零值、负值与位置问题。
4. T04：按模块提取计算层，逐个核对结果。
5. T05：完成必要的独立解析回归。
6. T06：修复 AI 跨块解析、停止和请求清理。

首批交付后推进 T07–T11，验收一个完整的可保存、可对比、可导出的实验流程。
