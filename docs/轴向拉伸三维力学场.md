# 轴向拉伸三维力学场

## 计算与显示

三维区复用 `calculateAxialTeaching → deriveAxialSpecimen → axialField`，不在绘图层建立另一条材料曲线。均匀直杆两端施加等大反向力，无中间轴向荷载。当前仅展示单调加载、均匀变形教学分支，不求解颈缩、损伤演化、裂纹扩展或卸载残余。

- 工程应力为 `F/A₀`，与材料教学曲线及右栏计算一致。
- 当前面积为 `A=A₀(1+εₜ)²`，三维使用面积等效的方截面。真实应力为 `σxx=F/A`，与工程应力分开标明。
- 弹性横向变形采用 `εₜ=-ν σeng/E`。金属非弹性分支复用原试件模型的弹性泊松收缩与塑性等体积伸长比分解，属于均匀变形教学近似。
- 当前构形的柯西面力 `t(n)=σn`。正法向截面上 `t=(F/A,0,0)`，积分合力为 `F`；自由侧面的面力为零。截面内力图层保留左段，右段半透明参照；面力箭头等长表示均匀分布，箭头长度不是应力量尺。
- 位移场采用中点参考坐标 `X∈[-L₀/2,L₀/2]`，`u=(εX, εₜY, εₜZ)`。位移基准仅消除刚体平移，不表示中点支座。两端位移差严格等于材料曲线给出的总伸长。
- 截面位置滑块显示距左端的原长坐标；读数中的 `X` 显示相对于中点的参考坐标。探针数值与放大倍率无关。
- 位移颜色编码有符号轴向位移，非应力梯度。零载荷不绘制位移色差。均匀应力不会在杆长方向衰减。
- 原长与宽度的画面比例用于教学，长细比不按真实比例绘制；轴向和横向位移共用放大倍率，并在面板上明确标注。尺寸与场读数仍使用真实计算单位。

## 模型范围

玻璃等脆性教学曲线超过参考抗拉值、金属超过教学峰值时，当前本构模型没有该试加载下的有效均匀静力分支。此时：

1. 保留未变形参考体，不制造固定宽度的裂缝开口，也不假定断裂位置。
2. 载荷标为试加载，`F/A₀` 标为名义需求应力；应变和伸长显示“未求解”。
3. 关闭贯通轴力图、定量三维场与粒子流，不能从模型缺失推断承载力为零。
4. 脆性材料显示教学参考载荷 `σt,ref A₀` 与试加载的比较。参考强度不是实测强度，也不是实际试件的安全判据。

未标定橡胶等材料不显示定量三维变形；静力平衡允许保留名义轴力，但该值不证明材料能够承受此载荷。

“载荷回零”仅创建零载荷独立工况，不模拟塑性卸载、残余应变或损伤恢复。
