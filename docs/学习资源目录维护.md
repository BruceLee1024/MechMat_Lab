# 学习资源目录维护

目录数据：`resources/catalog.ts`。界面：`modules/ResourcesModule.tsx`、`resources-library.css`。

## 本次调整（2026-10-21）

- 原 18 个条目整理为 14 个明确入口：11 个外部资源、3 个站内模块。
- 移除无明确作者/机构的 B 站条目、无对应内容链接的真题汇编和材料手册，以及没有核实图书入口的推荐卡片；不把它们伪装为“线下资源”。后续可在核对原始内容页后重新收录。
- 两本中文教材改为高等教育出版社产品信息页，保留作者与版次。旧 Abook 已公告迁移，避免用旧课程绑定入口作为默认目标。
- 未确认内容与开放状态的两条学堂在线课程暂不收录，替换为大连理工大学中国大学 MOOC 和 MIT 官方课程入口。
- 用 MIT 官方教材、讲义和习题目录替代没有来源的“免费资料”。不把教材产品页、登录课程页标为免费全文，也不把纯讲义课标为完整视频课。
- 去掉无评分依据的五星。每项资源标明语言、学习阶段、机构与使用条件。
- 常用公式、截面计算和基础实验调用已有模块导航，沿用原有激活检查。

## 核对依据

- [大连理工大学课程主页](https://www.icourse163.org/course/DLUT-1002170002)：课程名称、学校与材料力学范围。
- [刘鸿文《材料力学Ⅰ》第6版](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=59cf7f2cba9eb884cf823470)：作者、版本、目录和配套资源。
- [孙训方等《材料力学》第6版Ⅰ](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=619fc226938b7cc2960ede0d)：作者、版本与配套资源。
- [旧 Abook 迁移公告所在页面](https://abook.hep.com.cn/1237676)：2026 年 5 月旧平台注册/绑定服务停止，新平台为 `abooks.hep.com.cn`。
- [MIT 2.001](https://ocw.mit.edu/courses/2-001-mechanics-materials-i-fall-2006/) 与 [MIT 3.11](https://ocw.mit.edu/courses/3-11-mechanics-of-materials-fall-1999/)：课程名称、学期、级别与资料类型。教材、讲义和作业的下级页分别核对。
- GeoGebra、Desmos、LaTeXLive 使用各自官方编辑器入口，不链接泛化搜索结果或第三方搬运。

11 个外链在本机 HTTP 请求检查中均返回 200；这仅证明本次入口响应，不代表登录、视频播放、授权下载或未来可用性。出版社页的浏览器自动化内容读取超时，书目正文已通过官方页面文本另行核对；未测试账号内授权材料。请勿在界面显示永久“链接正常”承诺。

## 后续收录约束

每项必须有唯一目标（HTTPS 官方 URL 或站内模块 ID）、可辨识来源、明确的使用条件；外部条目保存核对日期。保留页面标题与作者一致的深层链接，不猜视频 ID，不把 HTTP 200 当作内容一致证明。新增后运行 `tests/resources.test.ts` 和 `tests/resourcesRendering.test.ts`，并实际检查目标内容及搜索、分类、移动端入口。
