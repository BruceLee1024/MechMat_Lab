# 应力状态可视化模型

应力模块沿用大画布、底部控制台、结果/理论分析栏。平面应力计算统一来自 `calculatePlaneStress`，三维单元体、莫尔圆、当前读数、报告与AI摘要共同使用该结果，不独立再算一套应力。

## 范围与符号

当前为平面应力：σz=τyz=τzx=0。三维单元体是此状态的立体表达，z面自由，不是完整六分量空间应力求解，也不计算材料应变或形变。历史文档中的隐藏面外分量保留，但不参与此视图或空间剪应力参考计算。

正应力拉为正、压为负。正τxy在+x面沿+y，在+y面沿+x；相对面等大反向。θ为x′轴从x轴逆时针旋转的角度，相机方位独立于θ。箭头长度按同一初始应力状态的面内主应力最大绝对值比例表达；旋转θ时比例尺不变，零分量不画箭头。

设 C=(σx+σy)/2，D=(σx−σy)/2：

- σx′=C+D cos2θ+τxy sin2θ。
- σy′=C−D cos2θ−τxy sin2θ。
- τx′y′=−D sin2θ+τxy cos2θ。
- R=hypot(D,τxy)，面内主应力σⅠ、σⅡ=C±R。
- 最大面内主应力方向θp=atan2(τxy,D)/2（180°周期）；最大剪应力平面与之相差45°。

主方向使用atan2区分象限，R=0时方向不唯一，禁止跳至一个虚构的唯一主方向。旧文档的超周期或负角度按等价180°周期显示；不改写原文档。

## 图形联动

三维方体绕z轴转θ，对四个x′/y′面绘制成对的正应力和互等剪应力；局部牵引按同一变换映射到全局。箭头压入/拉出的方向与数值正负相符。正视图可检查四面平衡，相机拖动不改变计算。

莫尔圆采用τ向上为正。X′=(σx′,τx′y′)、Y′=(σy′,−τx′y′)始终互为对径；θ逆时针增加时，圆上向量顺时针转2θ。灰虚线为初始方位；当前直径和状态点随θ更新。拖动X′点按两个极角差的一半反解θ，方向键也可每次调整1°；这些操作接入实验历史的连续手势合并。

SVG使用同一横纵比例尺，圆不因面板尺寸而变成椭圆。R=0时显示一个退化点，状态点不可拖动，明确说明任意面内方向均为主方向。

## 面内与空间最大剪应力

蓝色主圆只表示x–y面内变换，其半径R是面内最大剪应力。平面应力还存在零主应力；将σⅠ、σⅡ、0排序后，空间最大剪应力=(最大主应力−最小主应力)/2。

例如等双向60MPa拉伸，面内R=0，但包含自由z方向的空间最大剪应力为30MPa。界面和报告分别列出两者，不把R直接标为一般三维最大值。没有材料强度输入或强度通过判定。

## 输入与验证

初始σx、σy、τxy以MPa输入，可使用带符号数、滑块或教学示例。数值输入只有用户编辑过才提交，按Enter再失焦不会将已保存的高精度数值再次舍入回写；固定小数只用于显示。
