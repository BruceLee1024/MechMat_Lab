## 2. 单位与输入约束

| 物理量 | 输入/显示约定 | 内部约定 |
| --- | --- | --- |
| 力 | 基础模块 N，换算工具支持 kN | N |
| 长度 | 基础模块 m；截面和求解器坐标 mm | mm |
| 弹性/剪切模量 | 基础模块 GPa；求解器 MPa | MPa |
| 扭矩/弯矩 | 基础模块与求解器显示 N·m | N·mm |
| 应变能 | 拉伸、扭转 J；弯曲、求解器 mJ | N·mm＝mJ |

| 参数 | 提交约束 |
| --- | --- |
| 长度、面积、截面外尺寸、模量、参考屈服强度 | 有限且大于 0 |
| 基础载荷、压力、扭矩大小 | 有限且允许 0；方向沿用现有模块约定 |
| 应力分量、偏心距、求解器带方向载荷/坐标 | 有限带符号值；保留对应控件的指定范围 |
| 梁上载荷位置 | 0 至梁长；缩短梁后将位置限制到梁内 |
| 求解器单元载荷相对位置 | 0 至 1 |
| 泊松比 | 0 至 0.4999；自定义材料的 E/ν 更新同步推导 G |
| 扭矩分流比例 | 0 至 1 |
| 空心圆内半径、组合截面间距 | 允许 0；内半径必须小于外半径 |

输入框在失焦或 Enter 时提交，Escape 恢复上次有效值。空白、单独负号、小数点和不完整指数可作为编辑草稿，不写入计算参数。仅接受完整十进制/科学计数法；非有限值与不合法截面被拒绝。有限但导致结果溢出的输入给出诊断，可恢复当前实验默认参数。

## 3. 独立解析参考值

参考值直接来自下列解析公式，不以待测实现生成预期值。普通非零案例相对误差要求不大于 10⁻⁶；接近零的应力/力采用单位对应的绝对容差；测试中的小数精度比该要求更严格。

| 案例 | 参数与独立公式 | 参考结果 |
| --- | --- | --- |
| 轴向拉伸 | F=5000 N，A=100 mm²，L=1000 mm，E=200000 MPa；σ=F/A，ΔL=FL/(EA)，U=FΔL/2 | 50 MPa，0.25 mm，625 mJ＝0.625 J |
| 简支梁跨中集中力 | P=1000 N，L=2000 mm，矩形 b=100、h=200 mm，E=200000 MPa；I=bh³/12，M=PL/4，w=PL³/(48EI)，U=P²L³/(96EI) | 500 N 左/右反力，500 N·m，0.75 MPa，0.0125 mm，6.25 mJ |
| 偏置集中力 | 同上，a=500 mm；R左=P(L−a)/L，R右=Pa/L | 750/250 N；位置为 0 或 L 时弯曲应力、挠度为 0 |
| 生产简支梁入口 | P=1000 N，L=1000 mm，A=1000 mm²，I=10⁶ mm⁴，h=20 mm，E=200000 MPa | 500/500 N，250000 N·mm，2.5 MPa，52.0833333333 mJ |
| 悬臂梁端部集中力 | 同一生产梁，固定左端；w=PL³/(3EI)，U=P²L³/(6EI) | 固定端弯矩绝对值 10⁶ N·mm，端位移绝对值 1.6666666667 mm，833.3333333333 mJ |
| 圆轴扭转 | T=1000 N·mm，r=10 mm，L=1000 mm，G=80000 MPa；J=πr⁴/2，τ=Tr/J，φ=TL/(GJ) | 0.6366197724 MPa，0.0007957747155 rad，0.0003978874 J |
| 铰支欧拉压杆 | r=10 mm，L=1000 mm，E=200000 MPa；Pcr=π²EI/L² | 15503.13834015 N；长度加倍，临界力为四分之一 |
| 纯剪切与应力旋转 | σx=σy=0，τxy=30 MPa；主值 ±τ | ±30 MPa；45° 转换平面切应力为 0；一般工况保持迹与行列式 |
| 基础截面 | 矩形、实心圆、空心圆的面积和惯性矩解析式 | 包含内半径为 0 退化成实心圆；非法几何被拒绝 |

矩阵路径采用两个相同半载荷验证叠加，反力与应力应等于单个完整集中力案例。能量按实际位置间隔对分段线性弯矩平方积分，消除先前平均弯矩平方和固定间隔造成的偏差。
