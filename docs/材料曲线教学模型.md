# 轴向拉伸：材料曲线教学模型

本轮按用户确认采用“按材料特性的教学曲线”，不是牌号实测拟合。材料库只含 E、G、参考强度等，不能据此获得完整实测曲线。曲线类型、参考值的物理含义与计算适用范围分别处理。

## 材料映射

| 材料 | 教学响应 | 图表口径 |
| --- | --- | --- |
| Q235、Q345 | 弹性、理想屈服平台、强化、颈缩 | 使用 E 和参考屈服值，后续节点为教学设定 |
| Q460、铝合金、不锈钢、钛合金、铜 | 连续屈服 | Ramberg–Osgood 形式，0.2% 偏移参考 |
| 铸铁、玻璃、沿纤维方向的 GFRP/CFRP | 脆性 | 参考点前近似线性，不套金属塑性平台 |
| 混凝土 | 拉伸开裂与软化 | 无量纲形态；旧库压缩参考值不作为抗拉判据 |
| PA66 | 黏塑性形态 | 无量纲形态，温度、含水率和应变率未标定 |
| 橡胶 | 非线性弹性 | 无量纲形态，缺少超弹性参数 |
| 木材、胶合板 | 方向相关的拉伸形态 | 无量纲，未指定纹理或铺层方向 |
| 环氧树脂 | 脆性形态 | 无量纲，缺少固化条件与抗拉参数 |
| 自定义 / 预设名与 E、强度不匹配 | 线弹性参考 | 不猜测屈服后曲线 |

## 教学参数

这些参数只让课堂上的特征可见，不是试验数据、强度标准值或设计建议：

- Q235：平台结束应变 0.015、强化峰值应变 0.15、峰值应力 1.65 倍参考屈服值；Q345 分别为 0.01、0.12、1.5 倍。颈缩端点为峰值应变的 1.4 倍、峰值应力的 0.8 倍。未输出“材料实际断裂应变”。
- 连续屈服：ε = σ/E + 0.002 (σ/Rp0.2)^n。铝 n=10、不锈钢 n=6、铜 n=5、其余此类金属 n=12；教学峰值为不锈钢 1.8、铜 1.6、其余 1.3 倍参考值。峰后为形态示意，不反演下降支上的力控响应。
- 预设库原有强度字段名仍为 materialYield，以保持实验文件格式兼容。图表、设置和当前结果根据材料改用屈服、抗拉、压缩或未指定参考值标签；没有替换旧库参数为未经核对的新数值。

## 图、读数与输出一致性

`mechanics/axialResponse.ts` 负责材料映射、曲线采样与上升支应变；`calculateAxialTeaching()` 作为视图、AI 与实验报告的共同入口。

- 已匹配材料在上升支使用同一响应，当前点落在同一条教学曲线上。
- 理想屈服平台在力控制下应变不唯一，参考点选择平台起点并在计算警告中说明。
- 超过教学峰值 / 脆断参考值，或材料缺少标定时，不把当前估算值标到非线性形态曲线上；应变与伸长显示“线弹性估算”。这不是实际断后响应。
- 连续屈服、塑性、未标定及超范围工况不使用 U=F²L/(2EA) 作为有效应变能。报告和 AI 摘要同样过滤。
- 用户手改 E 或强度后切换为自定义材料，不能冒用原牌号的屈服后特征。材料预设切换仍保存材料名和原参数，无新增 JSON 字段。

## 三维试件与曲线的对应

`graphics/axialSpecimen.ts` 从 `calculateAxialTeaching()` 的结果派生几何，不另拟合应变。量化上升支采用 L=L₀(1+ε)，因此三维尺寸、总伸长和曲线当前点一致。

- 弹性横向伸长比为 λt,e=1−νεe，其中 εe=σ/E，ν 为当前材料参数。
- 对钢材强化、金属连续屈服，均匀塑性伸长比取 λp=(1+ε)/(1+εe)，横向伸长比 λt=(1−νεe)/√λp。塑性部分等体积仅用于教学几何；没有把工程应力当真实应力，也不模拟颈缩分布、损伤或卸载残余。这是即时加载状态演示，卸载按钮将参数归零。
- 纤维复合材料沿既定方向的横向尺寸采用库内等效泊松比，不表示完整的各向异性本构。
- 未标定材料、负载荷或超过金属教学峰值时显示未变形参考试件，当前长度标为“未确定”；不把线弹性估算驱动到材料非线性三维形态。脆性超过参考强度时显示断裂参考形态，开口不定量，内部应力粒子停止。
- 形变显示支持 ×1、×10、×80，轴向和横向位移共用倍率。过高倍率可能使显示截面翻转，此时自动降低共同倍率并显示实际倍率；相机只做等比适配，不再将轴向伸长截成固定比例。基础长细比仍为教学示意；尺寸标注始终显示未放大的计算值。

## 参考依据与边界

- [Ramberg & Osgood, NACA TN 902 (1943)](https://ntrs.nasa.gov/citations/19930081614)：连续非线性应力–应变的函数形式。本文给出的 n、峰值、平台和峰后节点是软件教学设定，并非该报告提供的这些牌号标定参数。
- [David Roylance, Stress-Strain Curves](https://eng.libretexts.org/Bookshelves/Mechanical_Engineering/Mechanics_of_Materials_(Roylance)/01:_Tensile_Response_of_Materials/1.04:_Stress-Strain_Curves)：不同材料族的拉伸曲线、塑性与脆性特征。不能据此推出某批材料的完整实测曲线。
- [Cambridge DoITPoMS, Poisson’s Ratio](https://www.doitpoms.ac.uk/tlplib/mechanical_properties/poisson.php)：弹性横向应变与轴向应变的比例。
- [Tomasz Wierzbicki, Incompressibility](https://eng.libretexts.org/Bookshelves/Mechanical_Engineering/Structural_Mechanics_(Wierzbicki)/11:_Fundamental_Concepts_in_Structural_Plasticity/11.03:_Incompressibility)：塑性体积不变的教学假设，不能与材料弹性泊松比混为一谈。

后续若需要实测拟合，需指定牌号、试件方向、温度、应变率、工程/真实应力应变口径及原始试验数据，并单独版本化保存标定参数。
